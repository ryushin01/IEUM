# 접근성 점검 (KWCAG 2.2)

33개 검사항목을 코드와 화면으로 직접 점검한 기록입니다. 항목 목록은 [비공식 정리본](https://a11ykr.github.io/kwcag22/) 기준이며, **인증을 받거나 전문가가 심사한 결과가 아닙니다.**

- 자동 검사: axe(스토리, E2E), 조작 영역 측정, 키보드 조작 E2E
- 하지 못한 것: 스크린 리더 실사용(VoiceOver, TalkBack), 마크업 검사기, 공식 기준 수치와의 대조

| 결과 | 뜻 |
|---|---|
| 충족 | 코드와 화면, 또는 자동 검사로 확인 |
| 일부 | 대부분 확인했으나 빠진 부분이 있음 |
| 미확인 | 사람의 실사용 점검이 필요 |
| 해당 없음 | 해당 콘텐츠가 없음 |

## 인식

| 항목 | 결과 | 근거 |
|---|---|---|
| 5.1.1 대체 텍스트 | 충족 | 게시 사진에 설명 입력, 없으면 작성자와 순서로 대체. 장식 아이콘은 `aria-hidden` |
| 5.2.1 자막 | 해당 없음 | 영상·음성 없음 |
| 5.3.1 표 구성 | 해당 없음 | 표 없음 |
| 5.3.2 선형구조 | 충족 | 헤더, 본문, 메뉴 순서. 넓은 화면의 왼쪽 메뉴는 DOM에서 본문 뒤 |
| 5.3.3 명확한 지시 | 충족 | 색이나 위치만으로 지시하지 않음 |
| 5.4.1 색 무관 인식 | 충족 | 좋아요는 아이콘 모양과 `aria-pressed`, 현재 메뉴는 배경과 `aria-current`, 본문 링크는 밑줄 |

| 5.4.3 명도 대비 | 일부 | axe로 라이트·다크 주요 화면 확인. 사용자가 올린 사진 위의 넘김 버튼과 공식 마크 아이콘은 개별 측정 안 함 |

## 이해

| 항목 | 결과 | 근거 |
|---|---|---|
| 7.1.1 기본 언어 | 충족 | `lang="ko"` |
| 7.2.1 사용자 요구 실행 | 충족 | 초점이나 입력만으로 화면이 바뀌지 않음 |
| 7.2.2 찾기 쉬운 도움 | 일부 | 약관과 처리방침은 설정의 같은 위치. 데모는 문의 메일이 없어 문의 메뉴를 숨김 |
| 7.3.1 오류 정정 | 충족 | 칸 옆과 경고 영역에 안내, 입력값 유지 (단위 테스트) |
| 7.3.2 레이블 | 충족 | 모든 입력에 레이블, 자리표시자에만 의존하지 않음 |
| 7.3.3 접근 가능한 인증 | 충족 | 붙여넣기와 자동 완성 허용, 인지 시험 없음 |
| 7.3.4 반복 입력 | 충족 | 같은 절차에서 다시 입력하게 하지 않음. 비밀번호 확인은 보안상 예외 |
